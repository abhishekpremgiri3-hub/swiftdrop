# Build SwiftDrop V8 as Android

This package is the prepared web + Capacitor source.

## On a computer
1. Install Node.js and Android Studio.
2. Open a terminal in this folder.
3. Run:
   npm install
   npx cap add android
   npx cap sync android
   npx cap open android
4. In Android Studio, build a debug APK with:
   Build > Generate Bundle(s) / APK(s) > Generate APK(s)

For Play Store, use:
   Build > Generate Signed Bundle / APK > Android App Bundle

Before production:
- Create the Supabase project.
- Run `supabase/schema.sql`.
- Put the Supabase project URL and publishable key into `www/config.js`.
- Enable Realtime for `orders`.
- Test authentication and Customer ↔ Rider flows on two physical devices.
- Configure a release signing key and Play App Signing.

Important: the `android/` directory is intentionally generated by `npx cap add android` on the target computer so the native project matches the installed Capacitor version.
